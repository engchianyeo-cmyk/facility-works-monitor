# FMWorks User Manual

## Access and navigation

Sign in with the assigned account. FMWorks requires a matching active profile and supported role. If authentication succeeds but the experience does not load, contact an Administrator rather than re-registering.

- **Home:** identity, KPIs, quick actions, recent work, attention queue.
- **Work Orders:** permitted search, filters, sorting, and detail.
- **Emergency:** incidents when the module is deployed.
- **Users/Departments:** role-restricted administration.
- **Footer:** version, build SHA, and environment for UAT/support.

## Work orders

Select **New Work Order**, enter a clear title, exact location, description, priority, and relevant references, then save a Draft or submit. Open detail to see assignment, dates, actions, and audit history.

Canonical statuses are Draft, Submitted, Approved, Assigned, In Progress, Completed, Reviewed, Closed, and Cancelled. Completed awaits review; Closed is terminal. Acceptance is recorded while status remains Assigned.

## Emergencies

Use **Report emergency** for urgent response, not to bypass normal approval. Provide type, severity, precise location, and actionable description. The incident remains valid when notifications are unavailable or no unique responder is resolved.

## Support

Safe errors identify authentication, access, validation, transition, reference, or configuration problems. Report build identity, route, time, action, and safe error code. Never send passwords, tokens, or service keys.
